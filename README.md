# 2D 뱀서라이크 게임 기획서

## 1. 게임 제목

**Project Survivor**

---

## 2. 게임 장르

2D 탑다운 생존 액션 게임  
Vampire Survivors 형식의 로그라이크 생존 게임

---

## 3. 게임 개요

플레이어가 2D 맵을 자유롭게 이동하며 지속적으로 등장하는 적들을 피하고 처치하는 게임이다.

플레이어의 공격은 일정 시간마다 자동으로 실행되며, 플레이어는 직접 이동하여 적과 거리를 조절하고 생존해야 한다.

적을 처치하면 경험치를 획득하며, 일정 경험치에 도달하면 레벨이 상승한다.

레벨업 시 능력치를 강화하거나 새로운 공격 능력을 선택할 수 있으며, 제한 시간 동안 살아남으면 게임을 클리어한다.

---

## 4. 게임 목표

게임의 최종 목표는 제한 시간 동안 몰려오는 적들을 처치하거나 피하면서 생존하는 것이다.

플레이 시간이 증가할수록 적의 수와 능력치가 증가하여 난이도가 점점 높아진다.

제한 시간이 끝날 때까지 생존하면 게임 클리어이며, 플레이어의 HP가 0이 되면 게임 오버된다.

---

## 5. 조작 방법

- W : 위로 이동
- A : 왼쪽 이동
- S : 아래로 이동
- D : 오른쪽 이동

공격은 플레이어 주변의 적을 대상으로 자동으로 실행된다.

---

## 6. 플레이어 시스템

플레이어는 다음과 같은 능력치를 가진다.

- HP
- 이동 속도
- 공격력
- 공격 속도
- 공격 범위
- 현재 경험치
- 현재 레벨

플레이어는 WASD 키를 이용하여 맵을 자유롭게 이동할 수 있다.

적에게 접촉하면 피해를 입으며 HP가 감소한다.

HP가 0이 되면 게임 오버된다.

---

## 7. 전투 시스템

플레이어는 일정 시간마다 자동으로 공격한다.

공격 시 플레이어 주변에서 가장 가까운 적을 탐색하고 해당 적에게 공격을 실행한다.

기본 공격은 투사체 형식으로 구현한다.

예)

플레이어 → 투사체 생성 → 적 방향으로 이동 → 적과 충돌 → 데미지 적용

적의 HP가 0 이하가 되면 해당 적은 제거된다.

---

## 8. 적 시스템

적은 일정 시간마다 맵의 외곽 지역에서 생성된다.

생성된 적은 플레이어의 현재 위치를 확인한 뒤 플레이어 방향으로 이동한다.

적의 기본 행동은 다음과 같다.

1. 적 생성
2. 플레이어 위치 확인
3. 플레이어 방향 계산
4. 플레이어에게 이동
5. 플레이어와 충돌 시 피해 적용

게임 시간이 증가하면 적의 수와 능력치가 증가한다.

---

## 9. 적 종류

### 일반 적

가장 기본적인 적이다.

- HP : 낮음
- 이동속도 : 보통
- 공격력 : 낮음

### 빠른 적

HP는 낮지만 빠르게 플레이어에게 접근한다.

- HP : 낮음
- 이동속도 : 빠름
- 공격력 : 낮음

### 탱커 적

이동 속도는 느리지만 HP가 높다.

- HP : 높음
- 이동속도 : 느림
- 공격력 : 높음

---

## 10. 경험치 및 레벨업 시스템

적을 처치하면 경험치 아이템이 생성된다.

플레이어가 경험치 아이템에 접근하면 경험치를 획득한다.

일정 경험치 이상을 획득하면 플레이어의 레벨이 상승한다.

레벨 상승 시 다음 능력 중 하나를 강화할 수 있다.

- 공격력 증가
- 이동속도 증가
- 공격속도 증가
- 공격범위 증가
- 최대 HP 증가

레벨이 증가할수록 다음 레벨에 필요한 경험치가 증가한다.

---

## 11. 난이도 시스템

게임 시간이 증가할수록 난이도가 증가한다.

난이도 상승 요소는 다음과 같다.

- 적 생성 속도 증가
- 적 최대 생성 수 증가
- 적 HP 증가
- 적 이동속도 증가
- 강한 적 등장

이를 통해 시간이 지날수록 플레이어가 더 많은 적을 상대하도록 만든다.

## 13. 주요 클래스 구성

### Player

플레이어의 상태와 이동을 관리한다.

주요 변수

- position
- hp
- speed
- attackPower
- attackSpeed
- level
- exp

주요 기능

- Move()
- TakeDamage()
- LevelUp()
- Attack()

---

### Enemy

적의 상태와 이동을 관리한다.

주요 변수

- position
- hp
- speed
- damage

주요 기능

- Move()
- ChasePlayer()
- TakeDamage()

---

### Bullet

플레이어가 사용하는 투사체를 관리한다.

주요 변수

- position
- direction
- speed
- damage

주요 기능

- Move()
- CollisionCheck()

---

### ExpItem

적을 처치했을 때 생성되는 경험치 아이템을 관리한다.

주요 기능

- 플레이어와 충돌 확인
- 경험치 지급

---

### GameManager

게임 전체 진행을 관리한다.

주요 기능

- 게임 시간 관리
- 적 생성
- 난이도 증가
- 게임 클리어 확인
- 게임 오버 확인

---

## 14. 충돌 처리

게임에서 필요한 주요 충돌은 다음과 같다.

### 플레이어와 적

플레이어와 적이 충돌하면 플레이어가 피해를 받는다.

### 투사체와 적

투사체가 적과 충돌하면 적에게 데미지를 적용한다.

### 플레이어와 경험치

플레이어가 경험치 아이템과 충돌하면 경험치를 획득한다.

충돌은 각 오브젝트의 위치와 크기를 비교하여 처리한다.

## 16. 게임 특징

본 게임의 가장 큰 특징은 복잡한 공격 조작 없이 이동에 집중할 수 있다는 점이다.

플레이어는 적의 움직임과 위치를 확인하면서 안전한 공간으로 이동해야 한다.

게임 시간이 증가할수록 적의 수가 증가하기 때문에 플레이어는 지속적으로 움직이면서 생존해야 한다.

또한 레벨업을 통해 캐릭터를 강화하여 플레이어마다 다른 성장 방향을 선택할 수 있도록 한다.

## 17. 개발 목표

본 프로젝트에서는 별도의 게임 엔진을 사용하지 않고 2D 게임의 기본 시스템을 직접 구현하는 것을 목표로 한다.

주요 개발 목표는 다음과 같다.

- 2D 플레이어 이동 구현
- 오브젝트 위치 및 상태 관리
- 적 추적 이동 구현
- 투사체 이동 구현
- 충돌 처리 구현
- 적 생성 시스템 구현
- 경험치 및 레벨 시스템 구현
- 게임 상태 관리 구현

이를 통해 게임 엔진에서 자동으로 제공되는 이동, 충돌, 객체 관리 등의 기능이 내부적으로 어떤 방식으로 동작하는지 이해하는 것을 목표로 한다.
